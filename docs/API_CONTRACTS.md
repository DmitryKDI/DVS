# Реестр внешних API-контрактов

Документ заполняется по фактическим материалам организатора. До изучения OpenAPI значения не предполагаются.

## 1. Реестр интеграций

| Система | Источник контракта | Base URL / среда | Авторизация | Статус проверки |
|---|---|---|---|---|
| ML-заглушка | OpenAPI организатора | Заполнить после проверки | Заполнить по спецификации | NOT RUN |
| ТОиР-заглушка | OpenAPI / описание организатора | Заполнить после проверки | Заполнить по спецификации | NOT RUN |

## 3. Правила

1. Не придумывать endpoints, поля, enum и HTTP-коды.
2. Не переименовывать внешние поля без явного mapping.
3. Не считать внутреннюю модель внешним контрактом.
4. Сохранять примеры фактических запросов и ответов в разрешённом правилами месте.
5. Отмечать расхождения между OpenAPI и фактической заглушкой.
6. Не считать повторный POST безопасным без подтверждения идемпотентности.
7. Секреты, токены и персональные данные не коммитить.

## 4. Неизвестные параметры

Смысл confidence, anomaly_score, диагностических статусов и порогов фиксируется только после изучения документации организатора. До этого любые пороги и трактовки считаются неизвестными.
