# План испытаний и приёмки

## 1. Правила фиксации

Для каждого теста сохранять:
- ID;
- предусловия;
- входные данные;
- шаги;
- ожидаемый результат;
- фактический результат;
- статус PASS / FAIL / BLOCKED / NOT RUN;
- ссылку на лог, скриншот или иной артефакт.

PASS ставится только после фактического выполнения.

## 3. Негативные и граничные тесты

- пустой или неполный ответ ML;
- неизвестный диагностический статус;
- некорректный тип поля;
- таймаут ML;
- недоступность ML;
- конфликт идентификатора автомобиля;
- неизвестное семейство двигателя;
- PDF без извлекаемого текста;
- страница с таблицей или схемой;
- неверный индекс страницы;
- совпадение текста в документе другого двигателя;
- противоречивые фрагменты;
- отсутствие доказательств;
- таймаут ТОиР;
- повторный клик подтверждения;
- изменение состава заявки;
- обновление страницы во время отправки.

## 4. Проверка доказательств

Для каждого отображаемого Evidence проверяется:
1. исходный PDF существует;
2. документ разрешён для данного двигателя;
3. индекс страницы указывает на правильную страницу;
4. фрагмент присутствует в оригинале;
5. контекст не меняет смысл;
6. процедура действительно относится к рассматриваемому случаю.

## 5. E2E сценарий

1. Открыть приложение.
2. Выбрать тестовый автомобиль.
3. Запустить получение диагностики.
4. Проверить исходный и нормализованный результат.
5. Открыть найденную процедуру.
6. Сверить PDF и страницу.
7. Просмотреть объяснение.
8. Создать проект заявки.
9. Проверить автомобиль, основание и состав работ.
10. Подтвердить конкретную версию заявки.
11. Проверить ответ заглушки ТОиР.
12. Убедиться, что результат сохранён и отображён.

## 6. Критерии релизной готовности

- все P0 E2E проверки пройдены;
- критические негативные сценарии проверены;
- нет известных дефектов, нарушающих безопасность или достоверность;
- запуск воспроизводим по инструкции;
- README соответствует фактическому состоянию;
- видео демонстрирует реальный работающий сценарий.

Непройденные тесты не скрывать: указывать BLOCKED, FAIL или NOT RUN с причиной.
