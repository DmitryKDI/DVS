# Матрица применимости технической документации

Матрица должна быть подтверждена по фактическим PDF и сведениям организатора. Наличие документа в списке само по себе не доказывает применимость конкретной процедуры.

## 1. Предварительный реестр документов

| Семейство двигателя | Предоставленный документ | Тип | Примечание |
|---|---|---|---|
| ЯМЗ-236М2 | Руководство по эксплуатации | Эксплуатация | Проверить редакцию и применимость |
| ЯМЗ-236М2 | Руководство по ремонту | Ремонт | Проверить редакцию и применимость |
| ЯМЗ-536 | Руководство по эксплуатации | Эксплуатация | Проверить редакцию и применимость |
| ЯМЗ-536 | Руководство по ремонту | Ремонт | Проверить редакцию и применимость |
| ЗМЗ-5234.10 | Руководство по ремонту | Ремонт | Проверить редакцию и применимость |
| ЗМЗ-40904.10 / ЗМЗ-40905.10 | Общее руководство по эксплуатации, ТО и ремонту | Смешанный | Проверять применимость к конкретной модификации |

## 2. Карточка документа

Для каждого PDF заполнить:
- исходное имя файла;
- контрольную сумму SHA-256 после получения;
- размер;
- редакцию / дату, если указана;
- двигатель и модификации;
- тип документа;
- число страниц PDF;
- наличие текстового слоя;
- страницы со сканами, таблицами и схемами;
- известные дефекты извлечения;
- ответственный за проверку.

## 3. Проверка применимости процедуры

Перед использованием фрагмента проверить:
1. двигатель и модификацию;
2. область применения руководства;
3. тип процедуры;
4. условия и ограничения;
5. совпадение содержания с диагностируемой проблемой;
6. исходную страницу PDF.

## 4. Правила отказа

- Если применимость не установлена — не выдавать процедуру как подтверждённую.
- Если документ не содержит нужной процедуры — сообщить об отсутствии подтверждения.
- Если страница плохо распознана — проверить оригинал вручную.
- Не переносить процедуру с похожего двигателя без документального основания.

## 5. Различие страниц

Хранить отдельно:
- индекс страницы PDF;
- напечатанный номер страницы, если он присутствует.

Не подменять одно значение другим.
