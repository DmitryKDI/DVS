# Матрица требований и прослеживаемости

Статус документа: базовая версия; подлежит сверке с первичными материалами организатора.  
Правило: требование считается подтверждённым только при наличии ссылки на первичный источник.

## 1. Обозначения

- P0 — обязательное условие основного сценария или безопасности.
- P1 — важная надёжность/удобство.
- P2 — дополнительная возможность.
- CONFIRMED — подтверждено материалом организатора.
- TO_VERIFY — требуется сверка с первичным источником.

## 3. Требования к данным и доказательствам

- Любое значение имеет известный источник.
- Внешний raw response не теряется при нормализации, если правила обработки данных это допускают.
- Неизвестные поля не превращаются в значения по умолчанию без обоснования.
- Единицы измерения и коды не меняются молча.
- Evidence хранит идентификатор документа, страницу PDF, текстовый фрагмент и статус проверки применимости.
- Индекс PDF и печатный номер страницы хранятся раздельно.
- Для каждого результата можно восстановить, на каких входных данных и источниках он основан.

## 4. Правило закрытия требования

Для перевода требования в DONE должны быть:
1. ссылка на источник требования;
2. реализация или обоснованное исключение из объёма;
3. тестовый сценарий;
4. фактический результат;
5. ревью ответственного;
6. отсутствие незакрытого критического дефекта.

Требования со статусом TO_VERIFY не должны трактоваться как окончательно подтверждённая спецификация.
