# Реестр недостающих входных данных

Версия: 1.0  
Дата фиксации: 22.11.2026  
Назначение: обеспечить быстрый старт без выдумывания контрактов, полей, статусов и правил.

## Правило ведения

Каждый пункт получает состояние:
- UNKNOWN — сведений пока нет;
- REQUESTED — запросили у организатора или участника;
- RECEIVED — материал получен, но не проверен;
- VERIFIED — материал изучен, источник и вывод зафиксированы;
- BLOCKED — отсутствие материала блокирует реализацию;
- NOT REQUIRED — подтверждено, что для задачи не нужно.

Не переводить пункт в VERIFIED только по устному предположению. Сохранять источник, дату проверки и ответственного.

## B. Данные, которые нужно извлечь из материалов

### Автопарк
- число записей;
- уникальность идентификаторов;
- связь автомобиля с двигателем;
- точное обозначение модели/модификации;
- обязательные поля для ML API;
- наличие тестовых диагностических проверок.

Ожидаемый масштаб по предоставленным ответам организаторов — 50 машин:
- ЯМЗ-236М2 — 13;
- ЯМЗ-536 — 12;
- ЗМЗ-5234.10 — 13;
- ЗМЗ-40905.10 — 8;
- ЗМЗ-40904.10 — 4.

Это контрольные ожидаемые количества, а не основание синтезировать отсутствующие записи.

### Диагностика
Для каждого фактического поля определить:
- источник;
- тип;
- обязательность;
- единицы измерения;
- допустимые значения;
- семантику;
- связь с автомобилем и проверкой;
- поведение при null/отсутствии/неизвестном значении.

Не присваивать полю смысл по названию без подтверждения.

### Документы
Для каждого PDF:
- точное исходное имя;
- SHA-256;
- редакция и дата, если указаны;
- семейство двигателя и область применимости;
- число страниц PDF;
- наличие текстового слоя;
- страницы со сканами, таблицами и схемами;
- способ проверки извлечённого фрагмента.

## D. Критерий готовности входных данных

P0-интеграция не начинается, пока соответствующий контракт не получен и не проверен. Если материал недоступен, задача получает BLOCKED с точным описанием отсутствующего элемента. Не заменять реальные данные фиктивными, кроме явно обозначенных тестовых fixtures, разрешённых условиями конкурса.
