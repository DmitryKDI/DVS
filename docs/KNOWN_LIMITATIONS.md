# Известные ограничения, риски и блокировки

Этот файл содержит только подтверждённые ограничения и вопросы, которые требуют проверки. Неизвестное не трактовать как установленный факт.

## 1. Внешние контракты

- [ ] Получить и проверить актуальную OpenAPI ML-заглушки.
- [ ] Получить и проверить контракт заглушки ТОиР.
- [ ] Установить фактические правила авторизации и ограничения.
- [ ] Уточнить, поддерживает ли ТОиР идемпотентность или ключ операции.

## 2. Диагностические данные

- [ ] Проверить реальные примеры всех диагностических статусов.
- [ ] Уточнить семантику confidence / anomaly_score, если эти поля присутствуют.
- [ ] Установить, как организатор кодирует сбой и плохое качество записи.
- [ ] Не назначать пороги до получения подтверждённой спецификации.

## 3. Документация

- [ ] Проверить все шесть PDF.
- [ ] Уточнить редакции и области применимости.
- [ ] Проверить страницы с таблицами, схемами и изображениями.
- [ ] Сверить индекс страницы PDF и печатный номер страницы.

## 4. Среда и разработка

- [ ] Подтвердить доступность внешнего LLM API и допустимые лимиты.
- [ ] Проверить доступное окружение и сетевые ограничения.
- [ ] Подтвердить, какие файлы и артефакты разрешено подготовить до старта.

## 5. Правило блокировки

Если для безопасной реализации отсутствует контракт, источник данных или подтверждение применимости:
1. отметить задачу BLOCKED;
2. указать конкретно недостающий материал;
3. приложить подтверждение проблемы;
4. не придумывать поведение;
5. запросить решение руководителя проекта или уточнение организатора.
