# Spec Delta

## Purpose

Связывает диагностическую проверку с выбранным автомобилем и применимой моделью двигателя.

Привязка к документации DVS: REQ-001–006, REQ-014–016 и T-001–008. Внешняя семантика подлежит сверке по docs/API_CONTRACTS.md.

## ADDED Requirements

### Requirement: Привязка диагностики к автомобилю

DVS MUST показывать диагностический исход для выбранного автомобиля и сохранять связь проверки с исходными идентификаторами, когда они доступны.

#### Scenario: Получен корректный ответ

- **WHEN** специалист выбирает автомобиль и сервис возвращает корректный ответ для его проверки
- **THEN** DVS показывает исход проверки и модель двигателя выбранной машины
- **AND** тестовый результат явно помечен, если источник синтетический

### Requirement: Обработка неподтверждённого результата

DVS MUST различать отказ сервиса, плохое качество записи и неизвестный статус. Такие исходы блокируют заключение и создание заявки по результату этой проверки.

#### Scenario: Данные непригодны для заключения

- **WHEN** сервис недоступен, запись непригодна или статус неизвестен
- **THEN** DVS показывает соответствующую причину без диагноза и заявки

#### Scenario: Отклонений нет

- **WHEN** фактический контракт подтверждает штатный исход
- **THEN** DVS показывает результат и не создаёт заявку на ремонт
