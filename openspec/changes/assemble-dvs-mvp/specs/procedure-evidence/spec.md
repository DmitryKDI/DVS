# Spec Delta

## Purpose

Позволяет механику проверить техническое основание объяснения по применимому руководству.

Привязка к документации DVS: REQ-007–009 и T-009–012. Матрица применимости и правила проверки страниц описаны в docs/DOCUMENT_MAPPING.md.

## ADDED Requirements

### Requirement: Проверяемый источник процедуры

DVS MUST использовать для объяснения только процедуру с подтверждённой применимостью к выбранному двигателю и со ссылкой на исходный документ и страницу PDF.

#### Scenario: Применимый источник найден

- **WHEN** для отклонения найден проверенный фрагмент подходящего руководства
- **THEN** DVS показывает процедуру и ссылку на документ и страницу
- **AND** объяснение различает результат ML, гипотезу и сведения из руководства

#### Scenario: Подтверждённого источника нет

- **WHEN** подходящий фрагмент отсутствует, страница не проверена или документ относится к другому двигателю
- **THEN** DVS сообщает об отсутствии подтверждённой процедуры и не предлагает её как установленную
