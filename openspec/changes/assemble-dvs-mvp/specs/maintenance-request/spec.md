# Spec Delta

## Purpose

Позволяет механику проверить черновик заявки и контролировать отправку конкретной версии.

Привязка к документации DVS: REQ-010–013 и T-013–017. Правило подтверждения версии закреплено в DEC-002.

## ADDED Requirements

### Requirement: Подтверждение версии черновика

DVS MUST отправлять только явно подтверждённую текущую версию заявки. Изменение содержания аннулирует подтверждение предыдущей версии.

#### Scenario: Отправка без актуального подтверждения

- **WHEN** специалист не подтвердил заявку или изменил её после подтверждения
- **THEN** DVS блокирует вызов ТОиР до подтверждения текущей версии

#### Scenario: Просмотр обоснованного черновика

- **WHEN** DVS готовит черновик по отклонению с подтверждённой процедурой
- **THEN** специалист видит предлагаемую операцию и её диагностическое и документальное основания

### Requirement: Фактический результат отправки

DVS MUST показывать успех только при подтверждении со стороны ТОиР и не выполнять автоматическую повторную отправку без подтверждённой гарантии идемпотентности.

#### Scenario: Ответ неоднозначен

- **WHEN** ТОиР вернул ошибку или исход отправки не удалось установить
- **THEN** DVS показывает ошибку или неопределённость без сообщения об успехе
