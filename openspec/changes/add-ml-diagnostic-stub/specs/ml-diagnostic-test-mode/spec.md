# Spec Delta

## Purpose

Позволяет проверять диагностическое поведение DVS на воспроизводимых синтетических данных до подключения внешнего ML.

## ADDED Requirements

### Requirement: Явное включение тестового источника

DVS MUST использовать синтетический источник только в тестах или при явно включённом локальном тестовом режиме. Выданный результат MUST быть помечен как синтетический.

#### Scenario: Локальный режим включён

- **WHEN** в локальном тестовом режиме выбран синтетический сценарий
- **THEN** DVS возвращает результат с признаком синтетического происхождения

#### Scenario: Тестовый режим выключен

- **WHEN** диагностика запрошена вне тестового режима и реальный источник недоступен
- **THEN** DVS сообщает о недоступности и не подменяет результат синтетическим

### Requirement: Воспроизводимые результаты

Для каждого поддерживаемого тестового сценария DVS MUST выдавать один и тот же диагностический исход при повторе с теми же входными данными.

#### Scenario: Норма и отклонение

- **WHEN** тест запускает сценарии нормы и отклонения
- **THEN** DVS различает их и возвращает ожидаемый исход для каждого сценария

#### Scenario: Повтор сценария

- **WHEN** тест повторяет сценарий с теми же входными данными
- **THEN** диагностический исход совпадает с исходом первого запуска

### Requirement: Безопасная обработка непригодных результатов

При плохом качестве записи, неизвестном статусе или недоступности источника DVS MUST возвращать различимые состояния без диагностического заключения.

#### Scenario: Непригодный или недоступный результат

- **WHEN** заглушка воспроизводит плохое качество записи, неизвестный статус или недоступность
- **THEN** DVS сообщает соответствующую причину и не формирует диагноз
