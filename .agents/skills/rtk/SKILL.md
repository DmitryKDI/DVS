Работай из корня DVS. Перед использованием проверь `rtk --version`.
Если CLI отсутствует, используй обычные команды или установи RTK по инструкции
в README DVS, когда задача включает настройку среды.

- Проверяй рабочее дерево через `rtk git status --short --branch`.
- Для обзора изменений используй `rtk git diff --stat`. Для ревью полного патча используй `rtk bypass git diff` или обычный `git diff`.
- Для приёмочных проверок используй `rtk bypass python3 -B -m unittest discover -s tests -v` и `rtk bypass npm run openspec -- validate ИМЯ --strict`. Подставь фактическое имя изменения.
- Фиксируй результат по коду выхода и фактическому выводу. Если нужен полный журнал, запускай команду через `rtk bypass` или напрямую.

Навык работает при прямом вызове CLI. Глобальный хук Codex настраивается отдельно в пользовательской среде.
